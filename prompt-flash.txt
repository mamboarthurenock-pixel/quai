Ajoute les FLASHCARDS (répétition espacée SM-2) et le GARDE-FOU anti-répétition.

CONTEXTE : la banque de questions existante est un tableau d'objets
{matiere, q, options, bonne, explication} dans app.js.

1. GARDE-FOU (localStorage) :
   - Clé "seen" = {idQuestion: timestamp}. Id = hash simple (matiere+"|"+q).
   - questionVue(id), marquerVue(id).
   - Dans le quiz et la roue : prioriser les questions NON vues (< 1 jour) ;
     s'il n'y en a plus, autoriser toutes.
   - Afficher "X jamais vues / Y" dans le quiz.

2. FLASHCARDS SM-2 (dans l'onglet Étude, section "Cartes") :
   - Bouton "🃏 Cartes du jour" + compteur de cartes dues.
   - Carte = question non vue ou due (clé "sm2" = {id:{interval,ease,due}}).
   - Recto : la question + bouton "Retourner".
   - Verso : la bonne réponse, l'explication, et "😊 Je savais" / "🤔 À revoir".
   - SM-2 : "Je savais" -> interval *= ease, ease = min(2.8, ease+0.1) ;
     "À revoir" -> interval = 1, ease = max(1.3, ease-0.2).
     due = maintenant + interval jours.
   - Marquer la question comme vue après chaque carte.
   - Passer à la carte suivante automatiquement.

3. style.css : styles des cartes (recto/verso, animation flip, boutons), compteur.
